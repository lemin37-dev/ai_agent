# 목표
- 에이전트는 LLM을 이용하여 추론(Reason), 행동(Act)을 교차 반복해서 문제를 자율적으로 해결 -> 인공지능 패턴 (ReAct)
- 한번의 ReAct 호출을 넘어서 결과를 검증하고 재시도하는 루프 구조 구성
- 제한을 두고 반복 수행 진행(임시) -> 비용/시간 절감 -> 처리가 되지 않으면, Human in the loop 적용
- `질문 -> 답변`인 기존 구조에서 `계획 -> 실행 -> 검증 -> 평가 -> 수정계획 -> 실행 -> ...` 작동하는 Agent 구성
- 이렇게 에이전트를 작동시키는 방식을 `루프 엔지니어링`이라고 함

# 구조
```
/
L app
    L loop_engine.py        : 루프 엔지니어링 기법 구성
L steps
    L step19_agent_loop.py  : 테스트 코드
```

# 특이점
- 출력 구조, 프롬프트를 다르게 부여하여 새로운 업무를 담당하는 에이전트 구성가능
```
model    = get_chat_model() # 단순모델
planner  = model.with_structured_output(Plan)       # 단순 모델 + 특이점 프롬프트 + 출력구조
verifier = model.with_structured_output(Verifier)   # 단순 모델 + 특이점 프롬프트 + 출력구조
build_graph()   # LangGraph 구조. LLM, tool 노드를 추가하여 규칙부여 -> 새로운 에이전트 구성
# 직선 구조가 완성되면 LnagChain 반영가능
```
